Files
=====
Downloadable documents live here and are linked with relative paths, e.g.

    <a href="assets/files/cv.pdf">Curriculum vitae</a>

One working placeholder PDF ships with the site so that no link is broken:

    cv-placeholder.pdf      linked from people.html as the group head's CV

Overwrite it with the real CV, keeping the same file name, and no HTML needs
editing. Add further PDFs here as you publish them and link to them from
teaching.html (shared notes) or resources.html (codes and data).

Keep file names lowercase and without spaces so the URLs stay clean, and
remember GitHub Pages is case sensitive.
